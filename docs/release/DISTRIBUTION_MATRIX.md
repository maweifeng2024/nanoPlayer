# Distribution matrix

| Platform | First package | Additional package | Signing | Status |
| --- | --- | --- | --- | --- |
| macOS 12+ | Universal DMG | `.app` archive | Developer ID + notarization | Debug `.app` verified; universal signed release pending |
| Windows 10+ | NSIS `.exe` | WiX `.msi` | Authenticode | Planned after macOS |
| Linux | AppImage | `.deb` | Checksums; repository signing later | Planned after macOS |

Release artifacts are generated by Tauri in `src-tauri/target/release/bundle/`. Copy only verified artifacts and `SHA256SUMS.txt` into a versioned release. The website must read the same release version used by the application config and must never advertise a file that has not been uploaded and checksum-verified.

Current local evidence is intentionally not a release artifact: `src-tauri/target/debug/bundle/macos/nanoPlayer.app` builds, opens, contains the configured icon, and passes native accessibility inspection. It is unsigned, debug-only, and must not be published as the universal DMG.
