# 桌面与移动 UI 重构记录

日期：2026-09-19。依据 `UI_IMPROVEMENT_PROPOSAL_2026-09-18.md`，本次实现范围由用户确认：**保留导航结构，全面优化现有页面**。提案仍是建议稿；本记录只列实际实现。

## 已实现

- **统一视觉基础**：七档间距、五档圆角、桌面 14px 正文 / 13px 辅文 / 11px 最小辅助字；安卓 16px 正文 / 14px 辅文。首页、歌曲、专辑、艺术家、歌单、设置、详情、队列共享刻度。首页 kicker 支持中英文；浅色首页去除遗留整列白底。
- **封面与列表**：常用行封面统一 48px、播放器封面 56px，统一圆角；清除旧表头规则和失效列模板，当前封面行通过 `--track-columns` 统一定义；播放中歌曲保留静态强调条和标题色，减少动效时仍可辨认。
- **桌面窄屏**：560/640px 进入紧凑播放器，保留封面、曲名、播放、队列与搜索；应用原生最小窗口尺寸未修改。首页列表也响应内容容器宽度。
- **手机 / Pad**：清除 Pad 封面行继承的 1120px 最小宽度；48px 图标命中区、8px 控件间距；手机两列专辑网格，Pad 独立页面边距；播放条、底部导航和抽屉使用统一高度变量与四边安全区；增加按压反馈和滚动隔离。
- **键盘和浮层**：歌曲行 Enter 播放、Space 播放/暂停、上下键移动、M 打开菜单；菜单支持方向键/Home/End，菜单项具备语义；对话框和菜单循环焦点、Escape 关闭、关闭后归还焦点；表格补齐 cell 语义。桌面支持 Escape 收起播放页。
- **选择与播放**：Shift 范围选择、Ctrl/Cmd+A 全选、Escape 退出选择（行内和工具栏均可）；标题按钮通过键盘可直接打开详情；Windows/Linux 快捷键显示 Ctrl；桌面拖动进度时预览时间和填充，释放后 seek；音量朗读百分比且不重复读数。
- **专辑/艺术家浏览**：进入详情前记录滚动位置，返回时恢复；虚拟网格按实际 CSS 列数、卡片高度和间距计算，不再依赖旧的 16px/166px 常量。
- **回归保障**：保存六张修改前参考图，建立六种尺寸/主题的 Playwright 像素基线，新增窄屏、键盘、滚动恢复和触控布局回归；`pnpm check:ui` 阻止字号、间距和圆角绕过共享刻度，已纳入 `pnpm check`。

## 与建议稿不同的实施判断

1. 播放器已经占据 Grid 的独立行，内容区不重复增加一整段播放器高度，避免双重留白；最后一首歌曲未被遮挡已由浏览器测试验证。
2. 移动图标按钮使用真实 48×48 命中区，不用相邻可重叠的伪元素扩展；主要输入维持触控尺寸。
3. 现有专辑卡片和队列播放按钮本来就是原生 button，保留其语义，不按建议稿改回模拟按钮。
4. 高度、标题栏安全距离、歌词底部空间属于布局几何，在 token 检查中明确保留；不会把所有像素值盲目归并成装饰间距。
5. 不加入新导航、最近播放入口、Pad 双栏或新手势，不改变首页返回时重新选择推荐的既有行为。

## 用户追加的五项修改

1. **移动端按钮反馈**：随机、循环、队列、歌词、收藏、静音统一 `aria-pressed` 与明显选中边框/色彩；原生上一首/下一首/seek 与轮询共用串行命令通道，执行后立即同步；旧快照不会覆盖尚未执行完的模式切换。相同队列轮询保留数组身份，避免队列菜单每 500ms 被关闭和滚动反复居中。
2. **随机播放**：桌面和 Android 新一轮随机顺序均以当前歌曲起始，余下歌曲随机排列，防止当前曲恰好排在末尾而只播放部分队列。Android 使用 Media3 的实际时间线返回 `playbackOrder`；队列顶部显示播放模式与真实下一首，原列表保留可编辑顺序。
3. **队列播完再播放**：增加明确的队列结束状态，点击播放开始当前整队的新一轮。Android 删除 `setMediaItem(current)` 这条丢弃队列的路径，改为 seek 回现有时间线第一首；保留原循环方式，普通暂停/恢复保持当前进度。
4. **背景过渡**：增加统一主题底色；真实封面取色层在上、下、左、右边缘渐隐回与相邻顶栏、侧栏、播放条一致的底色。系统栏也保持相同底色。没有真实封面的歌曲、解码失败或默认封面不触发新取色，保留上一次真实封面的颜色；首次启动使用中性背景。
5. **首页滚动**：桌面最近添加、播放最多、高评分取消各自固定高度和内部纵向滚动。列表按歌曲高度自然展开，整页统一滚动；手机已有横向推荐浏览继续保留。

追加验证：44 项前端单测；59 项浏览器 E2E；Android Kotlin 编译、5 项 JVM 单测、3 项 API 36 原生仪器测试；完整调试 APK 构建。实际日志见 `design/refactor-2026-09-19/native-verification.txt`。

实现依据参考 [Media3 播放列表与随机顺序](https://developer.android.com/media/media3/exoplayer/playlists)。原生随机序列以播放器时间线为准，UI 不自建另一套 Android 下一首逻辑。
