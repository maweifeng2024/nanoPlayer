# 0918 桌面、手机与 Pad 界面修正

状态：已实现并通过下述验证，未发布正式版本。基于本次开始前工作区已有移动端改动继续修正；本记录更新 0917 验收中“移动端隐藏删除歌单”的行为。

## 已实现

- 桌面更新通知显示 10 秒后收起，可手动关闭；本次启动不重复出现，下次启动重新检查并提示。设置中的检查、下载和安装入口保留。
- 歌曲、最近添加、高评分、播放最多、专辑及艺术家详情统一为封面、曲名、歌手与专辑、右侧更多操作。排序改为工具栏选择与方向按钮，评分和详情放在更多菜单。桌面歌单保留拖动和上下移排序。
- 首页三组推荐去掉边框和装饰横线，歌曲显示封面及两行文字，不再显示右侧播放图标。
- 手机和 Pad 首页封面置左，一句话与紧凑播放按钮置右；组间距增加，手机横向推荐统一卡片宽度。手机迷你播放栏采用三列布局，封面、文字、播放及队列入口垂直对齐。
- 手机资料库增加高评分 tab；手机与 Pad 侧栏在艺术家后增加歌单入口，移除侧栏原有新建歌单和具体歌单区。
- 歌单列表支持直接播放、重命名、删除；点击封面或名称进入详情，详情也可删除。删除前确认，仅删除应用歌单记录。
- 更多菜单按视口边界定位，五星评分完整显示。Pad 去掉旧表格列，避免日期和操作换到第二行。
- 缺少封面时使用新的唱片插画；展开播放页增加收起按钮，恢复来源页面、查询和歌单标识。
- 播放队列改用封面和歌手、专辑文字，更多菜单提供上移、下移和移除；桌面仍可拖动。
- 超过 40 首的歌曲列表虚拟化，封面读取最多 4 个并发，减轻首次挂载与原生图片解码压力。长文件夹路径可换行。
- 增强专辑封面取色背景的可见度。Android 将主题和封面取色混合出的底色同步到系统栏背景，同时更新深浅色图标。
