# Documentation archive

This directory contains dated investigations, proposals, audits, implementation records, and superseded visual evidence. Files are kept for decision history and should not be used as current status, architecture, command, or release authority.

- `audits/`: point-in-time environment and documentation audits.
- `plans/`: completed or superseded plans and proposals.
- `ui/`: dated UI review/implementation evidence and old wireframes.

When archiving a document, first carry any still-valid rule into a current document and update `docs/README.md`. Archived records remain historically accurate; avoid rewriting them merely to match today's file layout.
