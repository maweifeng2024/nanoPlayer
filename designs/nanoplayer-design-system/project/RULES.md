# 组件与跨端契约

|组件族 / 源码|开发规则|必须覆盖的状态|
|---|---|---|
|按钮 / styles.css + consistency.css|同屏一个主动作；移动44px最小命中；20px图标；禁用必须说明原因|默认、hover、pressed、focus-visible、disabled、pending|
|菜单 / useModalBehavior.ts|触发器再次点击关闭；Escape只关闭顶层；关闭返回焦点；长按与更多菜单内容一致|打开、关闭、边界避让、嵌套、滚动取消长按|
|确认框 / ConfirmDialog.tsx|标题说明对象；危险按钮描述结果；取消为明确出口；不以红色代替文字|键盘循环、遮罩、焦点回收、失败可重试|
|音乐行 / library/TrackTable.tsx|播放标识不盖封面；标题、艺术家、操作层级稳定；选择和当前播放可独立表达|长标题、无封面、已排除、播放、选中、虚拟滚动|
|播放器 / player/PlayerBar.tsx|主播放控制持续可达；进度与音量有标签；开抽屉不遮核心动作|无歌曲、暂停、播放、输出丢失、恢复|
|歌词 / lyrics/LyricText.tsx + PlayerDrawer|16–40px、默认24；每曲偏移±10秒/0.2秒；真实逐字时间才逐字展示|空态、普通/增强LRC、seek、翻译同行、离线失败|
|资料库 / LibraryPage + IOSLibraryPage|空态说明导入；权限问题给重新授权；跨集合选择规则一致|首次使用、扫描、空结果、权限丢失、混合歌单|
|设置 / App + UpdateSettings|名称、当前值、解释、操作层级一致；系统差异通过适配器表达|保存中、失败、系统限制、重启持久化|

## 布局

桌面保留侧栏、内容独立滚动、底部播放器和可选抽屉。手机导航遵循现有 PhoneNavigation。600–900px Pad 保留图标侧栏，不改成手机导航；窄分屏按既有已批准平台例外执行。安全区与系统标题栏占位属于布局几何，不塞进装饰 spacing 尺度。

回归宽度至少360/390、600/768/900/1024、720/1440；覆盖双主题和长中文/英文。每种同时记录平台和设备模式。减少动态效果设置下不以动画作为唯一状态反馈。10k列表应保持有界渲染；前端滚动测试不能替代原生队列响应测试。
